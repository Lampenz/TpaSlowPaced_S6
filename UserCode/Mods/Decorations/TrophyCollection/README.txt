Installation

Installation:

    Just extract "TrophyCollection.zip" into your /Mods/UserCode folder
    Contents include the trophy models and item scripts
    Restart your server and you're good to go!

Usage for Admins

    Use /give [Gold/Silver/Bronze]TrophyItem to award trophies
    Housing bonus values can be tweaked in the Item file
    Only admins can spawn or give these trophies
